# 画布反馈：让模型看见自己画了什么

## 要解决的问题

生成图里的碎片和错位，根源是模型"盲画"：它只看得到前面的 token，不知道画面现在什么样。
再加上训练时前缀永远是标准答案（teacher forcing），模型从没见过"前面画错了"的情况，
推理时一旦画偏就越错越远（exposure bias）。参考：Learning to Paint、Paint Transformer、
Compositional Neural Painter 都让每一笔看着当前画布决定；Self Forcing 用模型自己的输出训练。

## 设计

### 1. 什么时候看画布：检查点

在**每个图层标记**（LAYER / REDRAW / REFINE）和**每画 K=32 个图元**处设一个检查点。
检查点之后、下一个检查点之前的所有位置，都看"这个检查点时的画布"。

- 两个检查点之间，模型还有精确的 token 历史可用；画布提供的是空间上的总览。
- 一张约 730 个图元的人脸，检查点约 30 个。
- 只在检查点渲染，推理开销可控（见第 5 节）。

### 2. 看什么：64×64 的画布 + 每层覆盖图

输入 9 个通道，64×64：

| 通道 | 内容 | 为什么 |
|---|---|---|
| 3 | 当前合成画面 RGB（白底） | 画成了什么样 |
| 6 | 每个图层的累计覆盖 `1 - T_k` | 哪里是头发、哪里是皮肤；当前层画到哪了 |

画布就是我们的光栅化器（Triton / CUDA / HIP）在检查点处渲染出来的，训练和推理用同一个渲染器，
不存在"训练时看的和推理时看的不一样"。

### 3. 怎么编码：小 CNN → 8×8 个 token

`64×64×9 → (conv stride 2) ×3 → 8×8×d_canvas → Linear → 8×8×d_model`，加 2D 位置嵌入。
参数量很小（< 1M）。部署时它是一个独立的 ONNX 图，每个检查点跑一次。

### 4. 怎么用：主干里每隔几层加一次交叉注意力

- 查询：序列位置；键值：**该位置所属检查点**的 64 个画布 token。
- 每 4 个 block 后插一个交叉注意力层（base 16 层 → 4 层），带门控（初始化为 0），
  训练起点等价于原模型，可以从已有权重继续训。
- 训练时所有检查点的画布一次算好，交叉注意力用块状 mask（位置 t 只能看检查点 c(t) 的 token）。
  **整段序列并行训练不受影响。**

### 5. 训练时怎么渲染：前缀按绘制顺序渲染

检查点 j 的画布 = 序列前缀中所有图元，**按合成顺序**（图层号，再按层内顺序）渲染。
- full 模式下前缀本身就是合成顺序，可以用 over 运算的结合律做前缀扫描：
  每段只渲染一次，再累积 `(P, T)`，总代价约等于整图渲染一次。
- redraw / refine 模式下，尾部图元属于更早的图层，要插回到它所在图层的位置合成：
  按每层分别累积 `(P_k, T_k)`，检查点处再按图层顺序叠起来。每层覆盖图正好也是这样得到的。

### 6. 学会纠错：带错误的前缀

只加画布，模型看到的画布仍然永远是"正确的"，学不会纠错。所以训练时以概率 p 对前缀加扰动：

- 抖动：少量图元的位置 / 颜色 / 尺度加噪声；
- 删除：随机删掉几个图元；
- 插入：插入几个随机小图元（模拟碎片）。

扰动后的前缀同时进入 token 历史和画布；**后续目标仍是原来的标准答案**，loss 只算未扰动的位置。
模型由此学到"前面有错时，后面怎么接着画好"。

更进一步（第二阶段）：从被扰动的画布出发，用分解器继续拟合，得到"修补错误的后续图元"作为目标
（DAgger，专家 = 我们的可微分解器），让模型学会主动盖掉错误。离线计算较贵，视第一阶段效果决定。

## 推理开销

每个检查点：增量渲染自上一个检查点以来的约 32 个图元（只渲染新增部分，再 over 到已有画布上），
加一次小 CNN 前向。相对 32 步主干解码 + 32×9 步属性解码，开销很小。
C++ 运行时里，光栅化 kernel 因此从"数据预处理工具"变成"推理关键路径上的算子"。

## 验证

1. 单元测试：训练时的检查点画布 == 推理时逐步渲染的画布（逐像素）；交叉注意力 mask 正确；
   门控为 0 时输出与无画布模型完全一致。
2. 小规模实验：同样数据、同样步数，有 / 无画布反馈，比较验证 loss、孤儿率、生成图。
3. 扰动比例 p 的对照（0 / 0.3 / 0.5）。
