# 通用分层绘画：约束、候选方案与验证（2026-11-15）

本记录对应“扩充到风景、动物、物体，并让原图参与训练”的设计工作。
现有人脸模型与在跑的数据任务继续保留。本文件区分已经测到的结果和待验证的设计，
不把逐图优化收益当成生成模型收益。

## 1. 当前硬约束

- `protocol.json` 把图层编号和人脸语义绑在一起；事件、grammar、训练序列和采样器都依赖这些编号。
  把动物标签直接映射到“头发/五官”会混淆模型的语义。
- 上下文 1024 个位置，包含文字、控制事件和图元；不能只增加每层图元上限而忽略协议校验。
- 已分解的前 12000 张人脸平均约 729 个图元，重建平均约 26.01 dB。这是训练目标质量，
  与生成模型的验证交叉熵不是同一种指标。
- `Painter.forward()` 只监督事件/属性交叉熵；数据集没有把配对 RGB 返回给模型。
- 图元先生成离散属性再解码，argmax/采样本身不传梯度；可微渲染器不能自动消除这个断点。
- 当前分解器逐层拟合，并在每轮最后 30% 步数使用量化感知拟合。图元顺序在初始化时按 Morton
  安排，但位置随后会优化；不能假设最终位置仍严格按 Morton 排列。也不能直接重新排序，
  因为 alpha 合成有顺序依赖；若实验规范化顺序，需要重新拟合并检查图像是否改变。

## 2. 已做的诊断：原图与有界连续修正

脚本：`tools/probe_raw_supervision.py`。输入现有分解结果与对应原图，保持图元数量、所属图层、
层内合成顺序和硬度 beta 不变，仅允许小幅修正位置、尺度、角度、颜色和 alpha。

样本选择固定：分片 000 内按已有 PSNR 排序，在 10% 到 90% 分位之间等间距取 8 张，未按视觉效果挑图。
所有分支使用相同原图、初始参数、80 次 Adam 更新、参数范围和图层越界增量惩罚。

| 处理方式 | 8 张的平均 PSNR |
|---|---:|
| 已有离散训练目标 | 26.18 dB |
| 量化感知逐图修正：每步 snap，梯度使用直通估计 | 27.73 dB |
| 有界连续逐图修正 | 31.48 dB |
| 连续修正完再直接压回旧码本 | 27.42 dB |

量化感知对照从同一个初始参数重新开始，不沿用连续分支的优化状态。
“修正后直接 snap”不是量化感知优化，单独列出，避免混淆。

修正范围：xy 各不超过 2 个画布像素；log(sigma) 不超过 0.25；theta 不超过 0.25 弧度；
sRGB 与 alpha 各不超过 0.10。sigma、RGB、alpha 仍限制在合法范围；padding 图元保持透明。

初始实验中，连续分支的平均逐层越界量没有增加；单个样本/层的最大增量约 0.000064。
这是有限的检查，不等同于完整图层可编辑性验证。独立层外观与遮挡区域仍需另行评估。

结论：在这 8 个有原图的样本上，同样数量的广义高斯仍有明显的拟合空间；
现有码本/量化与拟合方式都是值得检查的因素。该结果不足以说明量化是唯一瓶颈，
也不能外推为风景、动物或自由生成的同等提升。

复现：

```sh
OMP_NUM_THREADS=4 LPP_EXT_BUILD=/tmp/lpp-native-verify \
  "$HOME/AI infra/.venv/bin/python" tools/probe_raw_supervision.py \
  --count 8 --steps 80 --quantized-control
```

原始指标和全样本对照：`out/raw_supervision_probe/metrics.json`、`comparison.png`。
精简图 `comparison_compact.png` 按原有选择顺序展示第 1、5 个样本，列为原图、已有目标、量化修正、连续修正。
这是拿着目标原图的优化诊断；尚未训练任何新的参数预测头，不是新生成模型或超分辨率结果。

## 3. 第一优先：离散结构 + 有界连续修正

保留两级 Transformer、事件 grammar、KV cache、CUDA/HIP 渲染器。离散分支决定图元和大致属性，
另加小头预测每个图元的有界参数修正。

训练思路：

1. 事件和离散属性继续交叉熵训练，保证语法与基本生成能力。
2. 在具有配对原图的 teacher-forced 样本上，预测小范围连续修正，再渲染与原图比较。
3. 图像损失回传到修正头与共享表示，不声称它直接训练了离散采样操作。
4. 输入修正头的是模型隐状态与当前图元属性。若推理时只给文字，修正头就不能依赖训练时才有的原图特征。
5. 先用像素与边缘损失；再单独消融多尺度/感知损失，避免一次引入太多变量。

形状残差适合放在唯一的 log 协方差空间。直接平均多个位置或旋转模式可能产生不存在的中间形状；
不把所有 token 概率的期望图元当作默认解法。log 协方差到形状的可微转换还需测试近圆形时的梯度稳定性。

输出记录需要新的协议版本携带残差。残差不必增加自回归位置数，但会增加字节数、输出头计算和运行时逻辑。
先用 float 残差验证价值，再测低比特定点残差的画质与部署开销；“序列位置不变”不代表代价为零。

必须报告三项：未见图片上的配对重建、自由生成质量、采样延迟。前者变好不能替代后两者。

## 4. 同时可做：改善纯离散教师

如果连续残差的部署代价不值得，可以保留纯离散格式，研究：

- 在分层拟合结束后进行全图联合量化感知微调，修复前后图层相互覆盖产生的残差。
- 对可信 mask 的边界、眼睛/嘴等关键部件加权，通用场景改用边缘、显著性与物体轮廓权重。
- 用未量化的拟合参数重训领域码本或残差码本，并将数据、码本、协议、checkpoint 一起版本化。
- 按“新增图元带来的误差下降/成本”分配预算，而不只按面积分配。

新的量化对照证明增加优化步骤本身有收益，但当前 80 步直通估计不是全局最优量化解，
需要多步数、不同学习率与独立样本验证后再决定是否全面替换数据。

## 5. 通用图层：实例与语义分开，遮挡分两档处理

新版本的图层表示应包含 `slot_id`（实例/编辑目标）、`semantic`（类别）、`paint_order`、可选 `parent`。
编号不再永久等于“皮肤/头发”。第一版先限制为背景与少量主体，复杂部件层级以后逐步加入。

COCO/ADE 等分割结果只说明可见像素归属，不提供完整的真实遮挡顺序或隐藏纹理。
采用两档能力，分别评估：

- 可见区域编辑：先保证每个对象能单独选择、重画，承认隐藏它后可能暴露未知区域。
- 可选遮挡补全：隐藏/移动对象时才生成合理背景或补全部件，明确是推测内容。

低置信度的伪标签边界只作弱约束；可信内部区域与原始 RGB 承担主要监督。
没有可靠 mask 的图片仍可训练单层粗绘/重建分支，不能据此声称获得了完整实例编辑监督。

## 6. 复杂图像：全局构图与局部补细节分开

单纯把上下文从 1024 拉到几千会增加训练和采样成本。候选替代方案：

1. 全局粗绘：预测少量主体布局和低频色块。
2. 细化：依据已渲染画布、文字/类别与待细化区域，按层生成局部补充图元。
3. 每轮只保留条件、全局摘要与局部上下文，使用新的短 KV cache；完整输出在外部按层保存。

复杂度可以分散到多次短解码，但总图元数、渲染和采样时间仍会上升。局部区域要有边缘重叠、
确定的合成顺序，并评估接缝与跨区域物体的一致性。图像到图元任务可以访问目标图裁剪，
自由生成任务只能访问文字、布局和当前画布，必须分别设计条件。

训练需逐步混入模型自己生成/扰动的粗绘前缀，检查它是否能修错；否则只在真实前缀上学习，
可能在生成时把早期错误一直放大。不要立刻采用全序列 scheduled sampling：先用局部扰动修复任务验证。

## 7. 原图的三种监督方式与成本

| 方式 | 是否需要图元标签 | 当前适合程度 |
|---|---|---|
| 原图 → 优化器 → 图元教师 → 自回归训练 | 由优化器生成 | 已有基线，最容易复用 |
| 配对原图 + 图元 → 连续修正/渲染损失 | 先用已有教师 | 下一步首选 |
| 原图编码器 → 连续图元重建 → 蒸馏到离散生成器 | 可逐步减少依赖 | 后续研究，先验证结构与训练成本 |

第三种路线可用已有分解结果训练一个初始化/提议网络，再用少量优化步骤修正，
目标是降低以后大规模造数据的成本。图像重建编码器不自动等于文本生成器；
文本生成仍需要学习配对文字到图元分布，或额外学习潜变量先验。

## 8. 实施与验收顺序

1. 保留当前人脸任务结果、协议和码本；完成已有分解与标注。
2. 把本次 8 张诊断扩到独立样本，比较纯离散联合微调和连续修正；同时检查图层质量、字节数与耗时。
3. 最有收益的方案再训练小修正头，验证未见图片与自由生成，决定是否进入正式协议。
4. 风景/动物/物体各约 500 张工程试验批，先以单主体/少主体为主，验证通用图层与预算分配。
5. 小规模混合训练，按内容来源分别报告质量；再扩大数据量和比较 small/base。
6. 局部细化作为可开关的质量档位，最后加入；后续二次元仍作为风格后训练。

没有证据前不停止原任务、不重做全部 3 万张、不把 RL/GAN 或更大的模型作为唯一方案。
图像奖励强化学习能绕过离散不可微问题，但长序列信用分配与训练稳定性增加成本，当前优先用已有解析梯度。

## 参考与适用范围

- [diffvg](https://cseweb.ucsd.edu/~tzli/diffvg/)：支持通过图像空间损失优化可微图元；
  不代表已经解决了本项目的离散自回归路径。
- [Im2Vec](https://arxiv.org/abs/2102.02798)：展示 raster-only 监督生成向量表示的方向；
  其结果不能直接外推到复杂照片与真实遮挡补全。
- [GaussianImage](https://arxiv.org/abs/2403.08551)：2D 高斯图像表示与量化参考；
  其累加合成与本项目的有序 alpha-over 不同，不能直接照搬重排或压缩假设。
- [Learning to Paint](https://arxiv.org/abs/1903.04411)：无人工笔画轨迹的图像监督绘画参考；
  RL 是备选，而非本月主线。

上述是文献启发与本项目的设计判断；只有第 2 节列出的逐图诊断已经执行。
