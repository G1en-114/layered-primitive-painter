## 更新：目标扩展到通用图像

用户补充要求：纳入风景、动物、物体，并考虑让原始图片参与训练。总目标调整为通用分层绘画，
下面的 FFHQ 路线保留为“人像子集扩充方案”，不再代表全部新增数据的优先顺序。

当前人像分解与标注任务继续完成，作为独立基线。下一批通用数据先从有现成分割标注的来源试验：

| 内容 | 首选候选 | 接入重点 |
|---|---|---|
| 动物、日常物体、多物体场景 | COCO Panoptic | 利用实例与背景区域，保留实例 ID 和类别 |
| 风景、室内外场景 | ADE20K 中筛选合适场景 | 合并区域，限制层数，检查细碎区域与遮挡 |
| 后续更多无人工 mask 的照片 | 经筛选的原图 + 分割伪标签 | 小样本验证后再规模化 |

来源：

- [COCO 官方 Panoptic 介绍](https://presentations.cocodataset.org/ECCV18/COCO18-Panoptic-Overview.pdf)
- [ADE20K 官方数据集与使用条款入口](https://ade20k.csail.mit.edu/)
- [SAM 2 官方介绍](https://ai.meta.com/research/sam2/)

先按风景、动物、物体各选约 500 张组成工程试验批；检查分解重建质量、图层可编辑性、
序列长度和成本，再决定扩大各类别的数量。按类别统计与采样，不用一个总样本数掩盖某类数据不足。

### 通用图层协议是前置工作

现有固定六层含皮肤、五官、头发，不能原样用于通用照片。新协议应分开表示：

- 图层的绘制顺序/实例槽位；
- 该层的语义类别，如天空、草地、猫、杯子；
- 可选的部件层级关系。

例如背景、草地、猫可以分别编辑；两只猫需要两个实例槽位，不能只因为同属“猫”就合成一层。
语义/全景分割只提供可见区域，不自动提供完整遮挡顺序或被遮挡内容；后两者若用深度与补全模型估计，
必须记录为伪标签。保持旧人像协议和 checkpoint 可复现，新协议、码本与数据使用新的版本。

先从单主体或少量主体的简单场景开始。当前平均约 729 个图元、最大 1024 个上下文位置的人脸配置，
不应直接承诺能覆盖复杂树林、毛发、建筑等细节；需要测量质量随预算的变化，再考虑分辨率或上下文扩展。

### 原始图片如何进入训练

必须保留同一样本的原图、对齐缩放后的图像、mask、描述和图元序列之间的关联。
原始图片既是分解器拟合的目标，也可以成为配对重建分支或图像到图元任务的监督。

当前 `Painter.forward()` 只计算事件与属性 token 的交叉熵，`SequenceDataset` 也未返回原始 RGB。
把 jpg 路径加进清单不会自动产生图片监督。新增图像损失前，需要数据加载、配对目标、
预测到渲染之间的可微路径，以及对应的评估。

离散 argmax/采样会切断梯度；仅有可微渲染器并不足以把图像损失传回 Transformer。
候选方案是先对连续参数预测/修正分支做配对渲染监督，或单独验证离散 token 的梯度近似。
图像损失只能用于有对应关系的训练目标，不能拿任意无条件生成图和任意一张原图计算逐像素误差。
加入输入原图条件则构成图像到分层图元任务，需要与文本生成任务分开定义输入与验证方式。

## 人像子集的目标与优先级

现有 CelebAMask-HQ 的 30000 张图片保留为人工分层标注基线。先完成全量分解和标注，
同时在小样本上改善分解质量，再逐批接入新的真人图片。二次元仍按原计划用于后训练。

扩充按三个阶段执行：

1. FFHQ 1000 张试验批：打通下载、分割、六层映射、分解和中文标注，检查分层质量与耗时。
2. 通过检查后扩至 20000 张新增图片：与现有数据合并前，跨数据源去重并固定训练/验证划分。
3. 根据效果和剩余机时，再扩至 FFHQ 的完整候选池。CelebAMask-HQ + FFHQ 理论上共 100000 张，
   实际有效数量应扣除验证集、重复图片和质检淘汰项，不预先承诺十万条训练数据。

## 为什么选 FFHQ

- 官方提供 70000 张 1024px 对齐人脸，年龄、族群、背景与饰品有较大变化，适合补充当前人脸生成任务。
- 官方 1024px 图像约 89.1 GB；不下载约 955 GB 的原始场景图。目前本机可用空间约 616 GB。
- 官方包不提供本项目需要的人工六层 mask，必须额外运行人脸语义分割并质检，不能直接投入现有分解器。
- 可用 CelebAMask-HQ 训练的 BiSeNet 输出 19 类，再按语义名称映射到本项目六层。
  不直接复用数字类别 ID：不同实现的类别编号可能不同。

参考：

- [FFHQ 官方说明、下载器、元数据与许可](https://github.com/NVlabs/ffhq-dataset)
- [BiSeNet 人脸分割实现、预训练模型与 ONNX 接口](https://github.com/yakhyo/face-parsing)
- [CelebAMask-HQ 官方来源与许可](https://github.com/switchablenorms/CelebAMask-HQ)

FFHQ 数据集采用 CC BY-NC-SA 4.0；各图片的作者与具体许可记录在元数据中，导入时保留来源信息。
CelebAMask-HQ 仅限非商业研究，项目仓库继续只发布代码与数据获取说明。

## 接入流水线

`FFHQ 原图 → 去重与固定划分 → 人脸分割 → 19 类语义到六层的映射 → 256px 图像/mask 分片`

随后复用：

`分层图元分解 → 重建与图层质检 → 中文描述 → 带来源信息的训练序列`

接入前需要补齐的工程工作：

- 统一样本清单记录 `source`、`source_id`、全局 ID、划分、许可与文件校验值。
  现有训练代码使用整数 image_id；新来源不能重新从 0 编号后直接拼接，否则会造成描述错配与划分冲突。
- 对原图及近重复图片先分组，再划分训练/验证。同一原图的翻转、裁剪、不同分解轨迹只能进入同一划分。
- 先在有人工标注的 CelebAMask-HQ 保留集上评估分割器，再抽查 FFHQ 中的侧脸、遮挡、帽子、眼镜等情况。
- 记录每个来源的采样权重，避免数量增长后的伪标签数据压过人工标注数据；具体比例由对照实验决定。
- 分开报告人工标注来源和伪标签来源的验证结果，保留固定无条件采样样图。
- 固定并记录协议与码本版本；更换码本后旧 token 的含义会改变，不可直接混用。

## 现有数据增强

已有 `tools/decompose_dataset.py --flip --seed 1` 支持翻转后重新分解。
30000 张原图各加一个翻转版本可以得到约 60000 条绘画轨迹，但独立原图仍是 30000 张。

翻转与轻微裁剪需要同步变换图片和 mask；涉及左右位置的中文描述也需同步修改。
不把旧文字描述直接用于改变了可见内容的裁剪，也不把大幅颜色增强后的图片配给原来的发色/背景色描述。
当前是离散形状码本，不能仅修改 x token 就声称完成了所有图元的精确镜像。

## 暂不优先的来源

- CelebA-HQ 与 CelebAMask-HQ 使用相同的那批基础图片，重复下载不会增加 30000 张独立原图。
- CelebA 的其他图片可作为后续候选，但需排除已有图片、检查分辨率并补分层伪标签。
- 动漫图片仍留给风格后训练，避免在当前真人基线尚未稳定时同时引入风格变化与新的分层噪声。

扩充解决覆盖度和泛化；分解器改进解决训练目标的块状与细节损失，两条工作线都保留。
